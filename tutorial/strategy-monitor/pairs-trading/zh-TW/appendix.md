# 公式、詞彙與實驗紀錄

繁體中文 · [简体中文](../zh-CN/appendix.md) · [English](../en/appendix.md) · [本版目錄](README.md)

## 常用詞

| 詞彙 | 在本書中的意思 |
| --- | --- |
| K 棒／觀測 | 一個時間區間的紀錄，例如一天的收盤資料。回測筆數按已記錄的時間計算，包含暖機或價格缺值的觀測。 |
| 價差 | 對兩邊價格加權後算出的差距。 |
| 避險比率 | 算價差時的相對權重。部分數量配置也會用它估算參考股數。 |
| Z 分數 | 價差偏離近期平均的標準差倍數。 |
| 暖機 | 累積足夠資料讓計算能產出數值的過程。 |
| 交易腿 | 配對中的一邊，具有自己的價格、數量和成本。 |
| 總名目金額 | 各邊價格 × 數量 × 乘數的絕對值加總。 |
| 回撤 | 累計損益由前面高點到後面低點的下跌。 |
| 保留期間 | 選規則前留下、用於後續檢驗的較晚資料。 |
| 來源紀錄 | 報告保存的價格資料來源與欄位對應。 |

## 公式速查

- **漲跌幅** =（新值 − 舊值）÷ 舊值 × 100。
- **固定價格價差** = 主要價格 × 主要乘數 − 比率 × 參考價格 × 參考乘數。
- **Z 分數** =（目前價差 − 最近 N 筆價差平均）÷ 這 N 筆的母體標準差，包含當前觀測。
- **單邊毛損益** =（出場價 − 進場價）× 帶符號的數量 × 乘數。兩邊相加。
- **估計淨損益** = 毛損益 − 已知或估計的成本。若從報告淨損益算，只扣尚未納入的成本；資金利息依報告列示另記。
- **進場總名目金額** = 各邊 `|進場價 × 數量 × 乘數|` 加總。報酬率的分母以所讀圖表或報告提示為準。
- **某筆的回撤** = 截至該筆的損益高點 − 該筆累計損益；最大回撤取其中最大值。

## 實驗紀錄表

每次實驗複製一份。在開啟保留期間的報告之前，先填完設定與放棄條件。

| 項目 | 你的紀錄 |
| --- | --- |
| 問題與標的順序 | 價差為何可能收回？哪一檔是主要？ |
| 放棄條件 | 哪些結果或資料問題會使你放棄這個假設？ |
| 輸入 | 各邊來源、確切欄位、週期、時區、觀測涵蓋情形。 |
| 規則 | 價差基礎、比率方法和數值、配適視窗、計算期數及出入場門檻。 |
| 數量與成本 | 配置方式、成交數量、乘數、手續費、滑價與借券假設。 |
| 建模與保留 | 請求及實際日期，確認無重疊，以及哪段資料用來選規則。 |
| 已存結果 | 報告名稱、資料筆數、暖機或缺值、已平倉筆數、總損益、回撤與未平倉。 |
| 自動回測（若有） | 範圍、m、n、筆數區間、種子、資料快照，以及是否有重疊。 |
| 模擬監看 | 讀取及觀測時間、資料狀態、訊號或略過原因、最終部位。 |
| 決定 | 繼續研究、修改後再測，或放棄。引用至少一個結果與一項限制。 |

## 期末報告示例

> 我在建模期後固定了台積電／聯電的規則。假設較早結果有六筆已平倉交易，較晚只有一筆結束且虧損，另有一筆未平倉。兩份報告使用同樣的價格欄位與成本假設。較晚樣本太少，原本的結果未獲確認。先保留作觀察，不改參數追上較晚資料。

本書截圖採用合成價格解釋畫面。請把自己的來源、期間和測試設定留在報告中，讓別人可以重做。

## 排查問題

| 狀況 | 先查什麼 |
| --- | --- |
| 清單沒有富果 | 確認 Terminal 已儲存自己的金鑰，重新打開新增策略。 |
| 看不到 Z 分數 | 查兩邊有無資料、暖機筆數，或一段價差是否相同。 |
| 沒有已平倉交易 | 查是否完全沒進場，還是已進場但未出場。 |
| 沒有報酬率 | 查是否有足以計算分母的進場部位。 |
| 種子相同、結果不同 | 查日期、來源、觀測列與設定是否相同。 |
| 停止後還有模擬數量 | 停止控制持續更新，另查平倉紀錄與最終數量。 |
