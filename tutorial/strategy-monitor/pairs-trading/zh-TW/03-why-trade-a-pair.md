# 第 3 章　為什麼把兩檔組成一對

繁體中文 · [简体中文](../zh-CN/03-why-trade-a-pair.md) · [English](../en/03-why-trade-a-pair.md) · [本版目錄](README.md)

配對研究從一個問題開始。**兩個標的的差距異常擴大後，有沒有反覆縮小的跡象？** 台積電和聯電都從事晶圓代工，可能受到部分相同的產業因素影響。兩家公司的產品、客戶與產能也有差異。因此同產業是一個研究起點，後面還要檢驗差距的行為。

兩檔股票如果常在同一天上漲，日報酬可能有正相關。若其中一檔一直漲得更快，兩邊差距仍可能越來越大。先決定用什麼方法量出差距，再看它在規則訂好之後的資料中，有沒有多次縮小。

| 研究筆記 | 台積電／聯電例子 |
| --- | --- |
| 可能一起變動的原因 | 兩家都從事晶圓代工。 |
| 可能分開的原因 | 個別公司的財報、產品組合或客戶需求改變。 |
| 要找的證據 | 按同一個公式算出的差距，在較晚的資料裡多次收回，幅度也可能涵蓋成本。 |
| 先寫下停止條件 | 差距一直擴大、資料不可靠，或結果幾乎都來自單一期間。 |

### 在策略監看操作

開啟第 1 章的配對，核對主要股票是台積電，參考股票是聯電。**順序會改變訊號的定義。** 交換兩檔會改變差距公式，也會改變範本在進場時買進哪一檔。在實驗筆記先寫下標的順序與上表的四項內容，完成回測再回頭檢視。

配對交易的早期研究曾用標準化歷史價格之間的距離選配對。它可以幫助理解研究背景。本書用加權價差與獨立期間檢驗自己的規則。[Gatev、Goetzmann 與 Rouwenhorst](https://www.nber.org/papers/w7032)

### 練習

兩檔經常一起漲，但差距已經連續九個月擴大。下一次差距偏大時，你會先查什麼？

先明確定義差距，查找過去類似變化後是否曾縮小，再以固定規則檢查較晚的資料。也應查看是否有兩檔各自的基本面變化。僅有同漲同跌的資訊，無法判斷差距會何時收回。
