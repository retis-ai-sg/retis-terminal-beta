# 第 3 章　为什么把两个指数放在一起

[繁體中文](../zh-TW/03-why-trade-a-pair.md) · 简体中文 · [English](../en/03-why-trade-a-pair.md) · [本版目录](README.md)

配对研究从一个问题开始。**两个标的之间的差距异常扩大后，是否常常缩小？** 上证指数和深证成指都反映中国内地股市的一部分，可能受共同的市场环境影响。两个指数的样本、行业构成和权重不同，也可能出现持续的分化。

同涨同跌和价差收回是两件事。两个指数若经常同一天上涨，日涨跌可能呈正相关。如果其中一个总是涨得更快，用同一公式算出的差距仍可能不断增加。先规定如何量出差距，再留出较晚的数据检验它是否回到原来的范围。

| 研究笔记 | 上证指数／深证成指示例 |
| --- | --- |
| 可能共同变化的原因 | 两者都受内地市场情绪影响。 |
| 可能分化的原因 | 行业涨跌不同，或指数权重及成分调整。 |
| 要找的证据 | 预先定义的差距在较晚的多个时段里反复收窄。 |
| 停止条件 | 差距持续扩大、数据不可用，或结论取决于少数日期。 |

### 在策略监看中观察

打开配对，确认上证指数是主要标的，深证成指是参考标的。**顺序很重要。** 对调标的会改动价差计算，也会改动模板两边的交易方向。记录这一组顺序与表中的四个判断，回放之后再检查哪里和预想不同。

早期配对交易研究用标准化历史价格之间的距离形成配对。本书采用加权价差，将同一套规则放到较晚的样本检验。[Gatev、Goetzmann 与 Rouwenhorst](https://www.nber.org/papers/w7032)
