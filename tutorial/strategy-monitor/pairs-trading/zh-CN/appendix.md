# 公式、词汇与实验记录

[繁體中文](../zh-TW/appendix.md) · 简体中文 · [English](../en/appendix.md) · [本版目录](README.md)

## 常用词

| 词语 | 在本书中的意思 |
| --- | --- |
| K 线／观测 | 某个时间区间的一条数据，例如一天的收盘点位。 |
| 价差 | 两项输入按指定权重算出的差距。 |
| 对冲比率 | 价差中参考标的的权重。某些配置也按比率计算模拟数量。 |
| Z 分数 | 价差偏离滚动平均的程度，以近期标准差为单位。 |
| 暖机 | 累积足够的有效观测，直到能计算指标。 |
| 交易腿 | 模拟配对的其中一边。每边分别记录数量和假设。 |
| 总名义值 | 两边数值 × 数量 × 乘数的绝对值加总。指数例中只是模型量。 |
| 回撤 | 累计盈亏从先前高点到之后低点的下降。 |
| 留出期 | 选参数前留出的、用来检验的较晚数据。 |
| 来源记录 | 把输入字段与外部数据对应关系保存在报告中。 |

## 公式速查

- **涨跌幅** =（新值 − 原值）÷ 原值 × 100。
- **固定比率价差** = 主要点位 × 主要乘数 − 比率 × 参考点位 × 参考乘数。
- **Z 分数** =（当前价差 − 最近 N 笔价差平均）÷ 这些价差的总体标准差，N 笔含当前一笔。
- **虚构股票单边毛盈亏** =（离场价 − 入场价）× 带正负号的数量 × 乘数。两边加总。
- **可交易标的净盈亏估计** = 毛盈亏 − 假设成本。若报告已含某项成本，计算时不要重复扣。
- **入场总名义值** = 两边 `|入场值 × 数量 × 乘数|` 加总。用报表提示中实际采用的分母计算模型回报。
- **某时点回撤** = 至该时点的累计盈亏最高值 − 该时点累计盈亏。取最大值就是最大回撤。

## 实验记录表

每个实验复制一份。开较晚的数据之前填好假设、设置和放弃条件。

| 项目 | 你的记录 |
| --- | --- |
| 研究问题 | 哪个指数是主要，哪个是参考？为什么可能有关系？ |
| 放弃条件 | 哪类持续分化或档案问题会让你停止？ |
| 输入 | 两指数代码、来源、字段、周期、时区和覆盖范围。 |
| 规则 | 对冲基础、方法、比率、拟合窗口、Z 分数周期和门槛。 |
| 模拟假设 | 两边的模型数量、乘数、费用和点位的用途。 |
| 建模期和留出期 | 请求日期、实际日期，以及这两段是否重叠。 |
| 已存回放 | 报告名、观测、暖机、缺值、状态变化、模拟盈亏和回撤。 |
| 自动回放（如有） | 抽样范围、m、n、长度、种子、快照和窗口重叠情况。 |
| 指数观测 | 至少两次读取时间、实际观测时间、两边点位、价差变化或取数失败。 |
| 决定 | 继续研究、修改后另测、放弃假设。写清证据和限制。 |

## 期末报告示例

> 我按相同数据字段计算上证指数与深证成指的加权价差，并在看留出期之前固定比率。较早的虚构报告多次回到平均附近。较晚的报告只出现一次明显回升，且有几个交易日缺少参考指数数据。我保留原始结果，先排查数据覆盖，再用另一段未看过的时期检验。观察结果只涉及两个指数的点位。

本书用合成点位说明界面与计算。你的报告请记录实际来源、日期和使用的价格字段。

## 排查问题

| 情况 | 先检查 |
| --- | --- |
| 没有历史来源 | Local yfinance 是否已运行，有无兼容来源覆盖两个指数。 |
| 只返回一只标的 | 核对 `.SS` 和 `.SZ` 后缀与来源覆盖。 |
| Z 分数空白 | 检查对齐、样本量和价差是否全相同。 |
| 回放没有已结束的部位 | 看是没有入场，还是只有入场标记而未结束。 |
| 相同种子不能重现 | 比较日区间、数据、抽样参数与设置。 |
| 反复刷新点位一样 | 核对观测时间，避免把重复读取记成新的市场数据。 |
